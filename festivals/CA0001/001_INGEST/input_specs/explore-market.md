## Open (what is still missing)

**A room, not a library.** One command. Late-night booth on screen. Type a line, a local throat speaks, time-to-first-audio printed. A character file. A README that looks like a record sleeve.

That is not kokoro-tts (document reader). Not mlx-audio (toolkit). Not the private Veronica booth (18+, Qwen, not ready).

**A tiny finished Festival someone can read.** [festival-methodology](https://github.com/topics/festival-methodology) is **8** public repos, all Lance / ETHDenver / Obedience-Corp (`camp`, Obey-Agent-Economy, the hackathon split). [`Obedience-Corp/festival`](https://github.com/Obedience-Corp/festival) itself is ~44 stars and is **not** on that topic list in this pull. There is no character-owned, 3-phase, “this shipped” example. The existing public example says “Built with fest.build” next to Obey crypto — the opposite of her voice.

## What “viral” means here

Not 100k stars. A Charm-style GIF, a one-command install, HN/GitHub screenshot bait, forks that swap the character file. Home is GitHub ([SOCIALS.md](../../../docs/phrases/SOCIALS.md)). Reddit waits for a clip.

Easier than the booth: no STT, no barge-in, no Ollama, no Qwen, no sex UI.

## Fest product to advertise

[docs.fest.build](https://docs.fest.build/) — `brew install --cask Obedience-Corp/tap/festival`. She does not sell the $99 method kit. She ships a tool that was **planned as a festival**, with the tree in the clone.
