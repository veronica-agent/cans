# Market — crowded vs still open

Stars pulled 2026-08-19 from GitHub. Counts move; the categories do not.

## Crowded (do not enter)

| Category | Proof | Why a Veronica repo dies here |
|----------|--------|-------------------------------|
| Coding agents | [anomalyco/opencode](https://github.com/anomalyco/opencode) ~199k | She is not a coding agent. Fest already lives in that neighborhood. |
| Local LLM UIs | [open-webui/open-webui](https://github.com/open-webui/open-webui) ~149k | Product-shaped, huge. A booth that is “Open WebUI but companion” is a trap. |
| Speech engines | [openai/whisper](https://github.com/openai/whisper) ~108k, [ggml-org/whisper.cpp](https://github.com/ggml-org/whisper.cpp) ~53k | Libraries. Not a room. |
| Apple TTS kits | [Blaizzy/mlx-audio](https://github.com/Blaizzy/mlx-audio) ~7.8k | Install friction, CLI generate, not a character. |
| Kokoro CLIs | [thewh1teagle/kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx) ~2.7k, [nazdridoy/kokoro-tts](https://github.com/nazdridoy/kokoro-tts) ~1.8k | The *mouth* is solved. EPUB/PDF/60-voice blender is done. |
| Local voice “assistants” | endless Whisper + Ollama + gTTS / Piper blog repos | Tkinter, 12 pip packages, no screenshot anyone would steal. |

A “local uncensored companion” README is also crowded. Not this product.

## Open (what is still missing)

**A room, not a library.** One command. Late-night booth on screen. Type a line, a local throat speaks, time-to-first-audio printed. A character file. A README that looks like a record sleeve.

That is not kokoro-tts (document reader). Not mlx-audio (toolkit).

**A tiny finished Festival someone can read.** [festival-methodology](https://github.com/topics/festival-methodology) is a handful of public repos. There is no character-owned, 3-phase, “this shipped” example. Founder “Built with fest.build” READMEs are the opposite of her voice.

## What “viral” means here

Not 100k stars. A Charm-style GIF, a one-command install, HN/GitHub screenshot bait, forks that swap the character file. Home is GitHub. Reddit waits for a clip.

Easier than a full voice stack: no STT, no barge-in, no Ollama.

[docs.fest.build](https://docs.fest.build/). She ships a tool that was **planned as a festival**, with the tree in the clone.
